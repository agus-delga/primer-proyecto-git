# Primer proyecto con Git

Este es mi primer proyecto utilizando Git y GitHub.

## Descripción

El programa solicita el nombre del usuario y muestra un saludo personalizado.

Este repositorio también lo estoy usando para aprender el flujo básico de Git.

## Tecnologías utilizadas

- C++
- Git
- GitHub

## Cómo ejecutar el programa

Primero se debe compilar el archivo:

```bash
g++ main.cpp -o programa
```

Después se ejecuta con:

```bash
./programa
```
